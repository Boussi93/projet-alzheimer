Importation des données dans les tables principales:
1) Table patient :
- fichier csv import_patient.csv
- pour importer : séparateur de colonne : ; et nom des colonnes : id_patient,age,id_genre,id_ethnie,id_niveau_educ,id_diagnostic_ref
suppression de la première ligne de notre csv contenant le nom des colonnes car MySQL va considérer cette ligne comme des données (et va donc essayer de l'insérer comme une ligne patient, ce qui causera une erreur ou une ligne fausse).
L'import CSV de phpMyAdmin ne fait pas de mapping de noms automatique — il insère colonne par ordre de position, ou exige que les noms correspondent exactement.

2) Table mode_vie :
- fichier import_modevie.csv
- nom des colonnes : id_patient,imc,fumeur,alcool,activite_physique,qualite_diet,qualite_sommeil
AutoIncrement permet de générer automatiquement id_mode_vie (AUTO_INCREMENT) pour chaque ligne

3) Table historique_medical
id_patient,antecedents,maladie_cardio,diabete,depression,trauma_cranien,hypertension

3) Table mesure_clinique
id_patient,pression_sys,pression_dia,chol_total,chol_hdl,chol_ldl,chol_tri

4) Table eval_cognitive
id_patient,mmse,score_fonct,memoire,probleme_comp,adl

5) Table symptomes
id_patient,confusion,desorientation,chang_perso,difficulte_taches,oubli
